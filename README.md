# Медцентр — тестовое PWA-приложение

Это устанавливаемая на телефон веб-версия прототипа. Она открывается как приложение без адресной строки после добавления на главный экран.

## Как быстро дать клиенту на тест

1. Распакуйте архив.
2. Загрузите **содержимое папки** на статический HTTPS-хостинг (например, Netlify Drop, Vercel или GitHub Pages). В корне сайта должны лежать `index.html`, `manifest.webmanifest`, `sw.js` и папка `icons`.
3. Откройте полученный HTTPS-адрес на телефоне.
4. iPhone: Safari → «Поделиться» → «На экран Домой» → включить «Открывать как веб-приложение» (если переключатель показан) → «Добавить».
5. Android: Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
6. Запустите появившуюся иконку. При первом запуске нужен интернет; после загрузки основные файлы кешируются для офлайн-открытия.

## Что работает в демо

- переходы между главной, каталогом, категориями, поиском, избранным, профилем и историей;
- открытие карточек услуг и нижних панелей;
- добавление/удаление услуг, изменение количества и пересчёт суммы;
- выбор даты и времени, демонстрационное подтверждение записи;
- истории, поиск, свайп вниз для закрытия нижней панели;
- сохранение корзины, избранного и демонстрационных записей на этом устройстве;
- адаптация под мобильный экран, PWA-иконка, standalone-режим и кеширование.
- выбор клиники с часами работы по дням недели; запись учитывает выходные и часы клиники;
- утренняя скидка на анализы: время до 10:00 помечено «−20%», сумма пересчитывается;
- после записи — что взять с собой (паспорт, СНИЛС, направление для медосмотров);
- раздел «Медосмотры»: профосмотр по 29н, ЛМК, психиатрическое освидетельствование;
- результаты анализов в личном кабинете (демонстрационные данные).

## Главный экран

Лента услуг — лист с тремя положениями: превью истории (так приложение открывается), лента во весь экран
(сверху остаются маленькие логотипы историй) и история на весь экран. Лист двигается пальцем за любое место ленты
(на компьютере — мышью или колесом); тап по превью или логотипу открывает историю.

## Что изменено относительно присланной версии

- Исправлено: часть стилей стояла после `</style>`, и на телефоне вместо приложения был виден текст CSS.
- Голубая тема: акцент `#0A6CF0` (контраст с белым как у прежнего розового), небесный `#2FA4FF` в градиентах,
  ледяные голубые фоны; иконка приложения голубая. В коде переменная `--accent` вместо `--pink`.
- Мутные фото-вырезки заменены векторными иллюстрациями; эмодзи в интерфейсе — иконками.
- Истории: превью при запуске, три положения ленты, автопереключение через 5 секунд, удержание — пауза.
- Шапка: слева — смена клиники, справа — личный кабинет.
- Услуга в записи: картинка серая с отметкой «В записи», кнопка цены — цвета корзины; повторное нажатие убирает
  услугу из записи.
- В карточке услуги время не повторяется дважды; дни недели в записи считаются от текущей даты.
- Сообщения «раздел в разработке» — всплывающей подсказкой вместо системного окна.
- Номер кеша `sw.js` поднят, чтобы установленное приложение подтянуло новую версию.

## Ограничения перед клиентским тестом

Это **интерактивный демонстрационный прототип**, а не подключённая медицинская информационная система. Записи не отправляются в клинику, реальные слоты не проверяются, оплата не проводится, уведомления и авторизация не подключены. Все данные локальные и демонстрационные. Для реальных пациентов нельзя использовать этот стенд для ввода персональных или медицинских данных.

Для очистки тестовых данных очистите данные сайта в настройках браузера.
